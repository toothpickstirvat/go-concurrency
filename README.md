# Go 并发编程课程

前置：已完成 `../fan-out` 项目，掌握 goroutine、channel、WaitGroup、select 背压。

每一节都是你写代码、Claude 检查并讲解。

---

## 课程目录

### 第一阶段：共享内存

| 目录                  | 主题         | 核心内容                                 |
|-----------------------|--------------|------------------------------------------|
| `01-mutex/`           | 互斥锁       | sync.Mutex、sync.RWMutex、锁的粒度、死锁 |
| `02-atomic/`          | 原子操作     | sync/atomic、适用场景、与 Mutex 的取舍   |
| `03-sync-primitives/` | 其余同步原语 | sync.Once、sync.Cond、sync.Map           |

### 第二阶段：控制与取消

| 目录          | 主题        | 核心内容                                   |
|---------------|-------------|--------------------------------------------|
| `04-context/` | Context     | WithCancel、WithTimeout、WithValue、传播链 |
| `05-select/`  | Select 进阶 | 超时、优先级、default 的副作用             |

### 第三阶段：并发模式

| 目录               | 主题     | 核心内容                                       |
|--------------------|----------|------------------------------------------------|
| `06-pipeline/`     | Pipeline | 多级 stage、背压、取消传播                     |
| `07-errgroup/`     | 错误处理 | golang.org/x/sync/errgroup、第一个错误取消所有 |
| `08-semaphore/`    | 信号量   | 限制并发数、weighted semaphore                 |
| `09-timer-ticker/` | 定时器   | time.Timer、time.Ticker、重置陷阱、停止泄漏    |

### 第四阶段：综合

| 目录           | 主题     | 核心内容                         |
|----------------|----------|----------------------------------|
| `10-capstone/` | 综合项目 | 把前面所有模式组合进一个完整程序 |
